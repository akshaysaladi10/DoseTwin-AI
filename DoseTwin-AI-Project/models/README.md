# Machine Learning Models Directory

This directory stores the serialized machine learning artifacts generated by the synthetic clinical training pipeline:

- `drug_response_rf.joblib`: Serialized Scikit-Learn `RandomForestClassifier` pipeline including `OneHotEncoder` and `StandardScaler` transformers.
- `model_metadata.json`: Model metrics, feature definitions, training sample size, and academic prototype metadata.

### Retraining the Model

To retrain the drug-response model on fresh synthetic physiological data, execute:

```bash
python backend/app/ml/train_model.py
```
